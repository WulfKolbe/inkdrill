THE FINDING, which is why 074 runs before 075
--------------------------------------------------------------------------
  tools/threeway.py -- a COMMITTED tool -- hardcodes this session's
  scratchpad:

      SCRATCH = pathlib.Path(
          "/tmp/claude-1000/-home-wkolbe-inkdrill/"
          "4c2bddec-f2e9-4179-ac4a-ae5869ace73a/scratchpad")

  Two consequences, and the second is worse than the disk:
    1. Deleting scratchpad/p13cmp breaks the P17 three-way tool.
    2. The tool is ALREADY broken for anyone else -- a different
       session, a different machine, or this machine after /tmp is
       cleared. It has only ever worked because it ran in the session
       that created the directory.

  So the right fix is not "keep the directory". It is to give
  threeway.py the same treatment reportcompare.py already has
  ($INKDRILL_WORK with a tempfile default), after which p13cmp
  becomes deletable like the rest. That is a code change, not a
  deletion, and it belongs to whoever schedules it -- flagged here,
  not done here.
