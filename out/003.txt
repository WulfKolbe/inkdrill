STEP 2 -- the redundant finds
=============================

Change (inkdrill/sweep.py)
--------------------------
1. `_UF.union(a, b)` is now `union_roots(find(a), find(b))`, and
   `union_roots(ra, rb)` holds the body unchanged. The size comparison
   and its tie-break were COPIED, not rewritten: with equal sizes `ra`
   stays the root, which is what makes a new run the root of the
   component it merges into.
2. The live sweep tracks `rn`, the root of the current run's component:
   `rn = nid` at creation, reassigned to the result of each
   `union_roots`. This removes
     - `uf.find(nid)` from every iteration of the edge loop
     - `uf.find(nid)` from the MERGE event
     - the two finds `uf.union` repeated on arguments already known
       to be roots

The reasoning that licenses it: a run is its own root at creation and
only `union_roots` can change that, and it returns the new root.
