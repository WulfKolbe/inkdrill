--------------------------------------------------------------------
1. THE DETECTOR

Built from 200's geometry and nothing else:

  1 the region's components, from the SOURCE page raster at 300 dpi
    -- each document's own pdf, never its report;
  2 the outermost delimiter pair: leftmost and rightmost components
    that `emit.is_delimiter` accepts -- a thin full-height stem with
    a full-width serif at each end and none in between, which is
    200's bracket measurement (normalised band centres 0.005 and
    0.985) read as a test;
  3 components lying entirely RIGHT of the right delimiter or BELOW
    the pair's common bottom;
  4 those grouped into text rows by `mathstruct.rows`.

`is_delimiter` and `crossing_rules` read the same band structure the
opposite way -- a crossing has an interior horizontal band, a
delimiter has none -- so neither can claim a component the other
claims. Asserted in the suite.

--------------------------------------------------------------------
3. THE CORRECTION THAT PRODUCED CLASS 2

The first run reported 156 qualifying and ZERO delimited-with-nothing
-outside. Every equation with a delimiter pair had something outside
it, which is implausible, and an empty class in a two-class
comparison built to make that comparison is the first thing to check.

The cause was immediate. The test included components LEFT of the
opening bracket, and everything left of an opening bracket is the
equation's LEFT-HAND SIDE. On EQ1059 -- the very case this detector
was built from -- `\psi =` sits there. A left-hand side is part of
the expression, not a label.

    before  156 class 1,  0 elsewhere
    after   146 class 1, 10 class 2, 0 class 3

Ten equations moved. Without the empty-class check, "156 of 2,135
equations carry labels outside their delimiters" would have gone into
this file looking entirely reasonable.

--------------------------------------------------------------------
4. WHY CLASS 3 IS EMPTY

The requirement is that each class has a member or the absence is
explained. Class 3 has none, so the branch was tested for
REACHABILITY on a synthetic region holding only `[ ... ]` -- two
bracket components and four cell blobs, nothing to the left, right or
below. It classifies as 3. The branch fires.

So the zero is a property of display equations rather than of the
code: a MathPix `math` region is drawn around a whole display
equation, and a display equation essentially always carries something
outside its brackets -- an `=`, a variable, a subscript, a trailing
period. A region that is only a bracketed matrix and nothing else did
not occur in 156 delimited equations across five books.

That is an observation about 156 cases, not a law. It would be
falsified by one region cropped tightly to a bare matrix, and the
test in the suite is exactly that region.

--------------------------------------------------------------------
5. WHAT IS NOT CLAIMED

- NOT that the outside rows are words. This project reads no text and
  has no word former: `group()` joins STACKED components -- an `i`
  with its dot -- never adjacent letters. The unit is the ROW. A
  label count would be the LaTeX's number, not the ink's.
- NOT that every class-1 equation carries prose labels. The class is
  geometric: ink right of or below the delimiters. On 200's case that
  ink is `up`, `down`, `strange`, `charm`, `flavors`, `red`,
  `yellow`, `blue`, `lilac`; elsewhere it may be a trailing
  punctuation mark or an equation number. Separating those needs
  symbol identity, which this project does not have.
- NOT a rate for the corpus. Five books chosen by the task, four of
  them from one publisher, and one of the five contributes zero for
  an instrument reason.
