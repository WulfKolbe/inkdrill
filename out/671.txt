====================================================================
1. WHAT WAS BUILT
====================================================================

  formulafind   `mathpix_readings()` reads `*.tiddlers.json` (exactly one,
                else nothing); field name in ONE constant, `MATHPIX_FIELD`,
                because pdfdrill will rename it `latex_mathpix` (their spec
                2026-09-14). A row whose shown reading differs carries
                `host_math`; `match_rows_first` looks it up by that and
                renders the shown reading as before. Recorded per row.
  formularesidual  `classify(..., line_h=)` pins the median line. Left to
                the population, `line_like` -- and so the mark -- of every
                row depends on which other rows are present.
  formulamarks  `update <bibkey> --work DIR`: measures only rows whose
                reading changed, plus never-placed rows whose MathPix
                reading differs, with `--scale` = the stored scale (no
                vote). `marks` merges: original records minus every id an
                update attempted, plus the update's records; calibration
                AND median line from the original run only.
